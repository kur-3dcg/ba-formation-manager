# 編成記録ツール

このツールはBlue Archiveの戦術対抗戦の防衛記録を保存して確認できるツールです。
先生名と編成を登録することにより、過去の履歴（30件）もさかのぼってみることができます。

---

## 🛠 機能一覧

### 🔷 編成登録・管理
- ユーザー名と編成（D1〜D4、S1〜S2）を画像付きドロップダウンから入力・登録
- **ユーザーアイコン設定**: ユーザー名に生徒一覧からアイコン画像を設定可能（未設定時は noimage 表示）
- **攻め編成の登録**: 防衛に対する攻め編成（A1〜A4、SP1〜SP2）も登録可能
- **検索機能付きドロップダウン**: 生徒名を入力してフィルタリング可能
- **選択解除**: 選択済みの生徒をもう一度クリックすると選択解除。選択中の生徒はリスト先頭に移動し ✓ マークで表示
- **ユーザー名オートコンプリート**: 入力欄フォーカス時に既存ユーザー名の候補を表示（「匿名」も含む）
- 登録データはローカルストレージに保存され、自動で復元されます
- **折りたたみ式フォーム**: 編成登録フォームは初期状態で折りたたまれ、「新規登録」ボタンで展開
- **名前の自動調整**: 10文字を超える名前は切り詰め、長い名前は文字サイズを自動調整

### 🟡 編集・上書き機能
- 編集ボタンで登録済みデータを変更可能
- **編集時は自動でフォームが展開**され、該当データが入力欄にセットされます
- 同名ユーザー名で登録すると上書きポップアップが表示され、意図しない上書きを防止します
- 編集中は入力欄が黄色でハイライト表示されます
- 中止ボタンで編集状態をキャンセル可能

### ⚔ 攻め編成の管理
- **攻めをクリアボタン**: 攻め編成（A1〜A4、SP1〜SP2）を一括で空白に
- **元に戻すボタン**: クリア前の攻め編成に復元可能
- **攻め表示/非表示の切り替え**: ボタンで攻め列の表示を切り替え
- 表示状態はブラウザを閉じても保存されます

### ⭐ Fav機能
- 重要な相手をFavに登録
- Favは**常に最上部に表示**
- Favの行は左端に黄色のラインで視覚的に区別

### 🎭 匿名自動振り分け機能
- ユーザー名を「**匿名**」で登録すると、D1・S1・S2の育成状態（★/固有レベル）を指紋として自動判別
  - 一致0件 → 新規プロファイル「匿名_001」「匿名_002」… を自動作成
  - 一致1件 → 対応プロファイルへ自動割り当て（旧データは履歴へ退避）
  - 一致複数 → 判別ダイアログを表示してユーザーが選択
- 匿名_XXX はお気に入りの次（テーブル上部）に常時表示（薄紫の左ボーダー）
- **🎭 匿名振り分けボタン**: 既存の「匿名」エントリをまとめて振り分け整理可能

### 🧾 履歴表示機能
- 各編成の過去履歴を最大30件まで保存
- 「履歴」ボタンで編成履歴を展開／折りたたみ可能
- 履歴にはキャラ画像と日付（年/月/日 時:分）が含まれます

### 💎 固有レベル設定
- D1・S1・S2 選択時にダイアログで ★1〜★4 / 固有1〜固有4 を設定可能
- デフォルトは固有2（スキップで未設定のまま登録）
- 設定済みのレベルはアイコン上にバッジ表示

### ❗ 警告・重複チェック
- **防衛・攻めそれぞれで重複チェック**: 同じキャラを複数枠に入れた場合、行背景が警告色で表示されます
- **未選択は重複としてカウントしません**

### ⬆️⬇️ ソート機能
- 名前・日付などの列をクリックすると昇順／降順ソートが可能
- **デフォルト順**: お気に入り → 匿名_XXX → 戦闘回数（登録・更新回数）の多い順
- ソート中は「▲」「▼」で表示状態を明示
- **Favは常に上部**に表示されます

### 📤 インポート / エクスポート機能
- JSON形式でデータをエクスポート／インポート可能
- 他ブラウザへの移行やバックアップ用途に対応
- **既存データとの互換性維持**: 古いデータをインポートしても新機能のフィールドは自動補完されます

### 📝 メモ機能
- 編成登録時に自由入力可能な「メモ欄」を追加
- **メモの折りたたみ表示**: デフォルトは非表示、「メモを表示」ボタンで切り替え
- **表示状態を保存**: ブラウザを閉じても設定が維持されます

### 🧹 履歴の個別削除
- 履歴表示内のエントリごとに ❌ 削除ボタンを追加
- ボタンを押すと該当エントリのみを削除可能（確認ダイアログ付き）

### 🔍 攻め履歴検索
- 防衛編成の条件を指定して、過去にどんな攻めをしたか検索可能
- STRIKER（D1〜D4）は指定したスロットのみ位置一致で判定（未指定スロットは無視）
- SPECIAL（S1〜S2）は順番不問で判定
- 履歴データと現在の編成を横断検索し、結果を日付順に表示
- 結果には防衛・攻め両方の編成が画像付きで表示されます

### 🗃️ 所持キャラリスト表示
- 履歴から使用されたキャラを抽出し「所持キャラリスト」として表示
- 「所持」ボタンから該当ユーザーの履歴キャラを画像で一覧化
- 未選択・削除済み履歴のキャラは対象外

### 🐦 共有
- Twitterに共有したい防衛・攻め編成を投稿できます

## 📱 操作ボタン一覧

| ボタン | 機能 |
|--------|------|
| ⭐Fav | Favに登録/解除 |
| 🔧編集 | 編成を編集 |
| 🗑️削除 | 編成を削除 |
| 📜履歴 | 過去の編成履歴を表示 |
| 🗃️所持 | 履歴から所持キャラを一覧表示 |
| 🐦共有 | Twitterに編成を共有 |
| 🎭匿名振り分け | 「匿名」エントリをプロファイルへ一括振り分け |
